Solved the Sqrt(x) problem where we have to find the square root of a number without using any built-in functions or formulas.
The algorithm initially has a time complexity of O(sqrt(x)) and O(1) space complexity which resulted in a 11ms/9ms of runtime.
Tried a different approach by implementing the binary search in the code and re-coding the algorithm.
The final algorithm has a time complexity of O(log n) and space complexity of O(1) which resulted in a runtime of 0ms and 8.46 MB memory.
