Solved the "Maximum Average Subarray I" problem where we have to find the maximum average for k contiguous elements in a given array of integers and return the maximum average in double.
Used the sliding window approach to solve the problem where I set the right at left + k distance to setup my window.
The final algorithm has a time complexity of O(N) and a space complexity of O(1).
It has a runtime of 0ms and 113.88 MB of memory.
