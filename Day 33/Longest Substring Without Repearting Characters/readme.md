Solved the "Longest Substring Without Repeating Characters" where we have to find the length of the longest substring that exists within a string and has no repeating characters.
Used Dynamic Sliding Window approach to solve this starting from index 0 and also used an array of size 128 to store them as ASCII indexes.
The final algorithm has a time complexity of O(N) and space complexity of O(1).
It has a runtime of 0ms and memory of 18.28 MB.
