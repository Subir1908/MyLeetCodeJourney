Solved the Maximum Depth of a Binary Tree Problem where we have to find the maximum depth a given binary tree has.
Algorithm uses recursion and stack to manage the nodes of the tree by storing them and also stored the left and right depths.
The result is the maximum of the left and right depths plus 1 for the root node.
The algorithm has a time complexity of O(N) and space complexity of O(H) for stack.
The algorithm has a runtime of 0ms and 22.35 MB (needs optimization).
