Solved the 3Sum problem where we have to find three numbers from a array of numbers that add up to 0.
Used two pointer technique to solve this by first sorting the aray, fixing the first number and then using two pointer for the values greater than the fixed number.
The final algorithm has a time complexity of O(N^2) and space complexity of O(1) or O(log N) which are optimal given the problem.
The algorithm has a runtime of 43ms and 28.99 MB of memory which are also in the optimal range.
